Methodological Disclosure: Test Set Prevalence Shift

Test set fraud prevalence is 1.562% (1,618 / 103,591), compared to 0.129% in the full dataset and 0.088% in the training split. Assuming constant TPR (0.483) and FPR (0.00121):

  • Full Dataset Prevalence (0.129%): GBT precision would drop from 0.864 to approximately 0.341 (34.1%).
  • Training Split Prevalence (0.088%): GBT precision would drop to approximately 0.261 (26.1%).
